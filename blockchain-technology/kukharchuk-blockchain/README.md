# Simple Blockchain

A small demonstration of a blockchain implementation in Go.  
This project is for **learning purposes**—to show the basic principles of blocks, transactions, and a simple Proof-of-Work algorithm.

---

### Ethereum
Install [Geth(Go-Ethereum)](https://geth.ethereum.org/downloads)
```bash
brew install ethereum
```

Create new account by Geth
```bash
geth account new
```

```bash
geth account list
```


### Run the Project

```bash
go run ./cmd/server
```
